Entry for the make.fun bounty **Real-Life Patch Notes: The Comedy Changelog** — one line, at most 160 characters: a software patch note for a bug in real life or human biology, in the terse register of a real release note. This one ships the fix every insomniac has been waiting for: the brain no longer replays your most embarrassing moment from 2014 at 3 a.m. instead of letting you sleep.

## Run

```sh
python3 main.py
```

This writes the patch note to `output/entry.txt` (UTF-8, no trailing newline). To write to a different directory, set `MAKEFUN_OUTPUT_DIR`:

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
